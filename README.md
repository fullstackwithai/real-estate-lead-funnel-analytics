## Real Estate Lead Intelligence Theme

This repository is presented as a premium PropTech analytics dashboard for tracking real estate leads, listing inquiries, agent response speed, viewing requests, pipeline stages, and conversion performance.

| Theme Layer | Direction |
|---|---|
| **Design Identity** | Gold, cyan, charcoal, and premium PropTech funnel accents |
| **Product Feel** | Real estate lead command center / agent pipeline analytics dashboard |
| **Audience** | Real estate agencies, agents, PropTech founders, BI hiring managers |
| **Core Message** | Leads + listings + follow-ups + appointments + conversion insight |

---

## Lead Funnel KPI Layer

| KPI | Purpose |
|---|---|
| **New Leads** | Tracks inquiry volume across listings |
| **Response Time** | Measures agent follow-up speed |
| **Viewing Requests** | Shows serious buyer/renter interest |
| **Conversion Rate** | Tracks movement from inquiry to appointment |
| **Top Listing Source** | Identifies listings that generate the strongest demand |
